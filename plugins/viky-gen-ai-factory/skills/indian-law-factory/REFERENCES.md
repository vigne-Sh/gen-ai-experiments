# References — index

`SKILL.md` is a research method, not a stored copy of Indian law.
This directory is where the specific facts it's built on live — each
domain file below records exactly what was independently checked
against a live source (not recalled from memory alone), when, and
against what — and, just as importantly, what within that domain
*hasn't* been checked yet. Point users here if they ask where a claim
comes from, or which domain file to read for more depth.

Each file follows the same format: a table of specific claims with the
source(s) checked and a "not independently verified in this pass"
section naming what within that domain still needs a live check before
relying on it. None of these files are exhaustive of their domain —
Indian law is far larger than any reference collection a skill can
reasonably maintain — they're a verified starting map, not a substitute
for `SKILL.md`'s live-research protocol on anything not listed here.
