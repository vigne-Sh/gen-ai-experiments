# Tamil Language Factory

See `REFERENCES.md` (same directory) for the specific historical/script
facts this file relies on (letter counts, Tolkāppiyam, classical-language
status), each checked against a live source, with the date checked.

## Steps
1. Clarify what's actually needed before answering: translation direction,
   register (spoken/colloquial vs. literary/formal - see 'Registers'),
   whether Tamil script or a transliteration is wanted, and which variety
   of Tamil if it matters (see 'Regional and historical varieties').
2. For a document: read the whole thing first. If it's OCR'd or a photo
   and some characters are unclear (Tamil's uyirmei combinations are easy
   to misread as similar-looking ones), say which parts are uncertain
   instead of silently guessing a plausible-looking word.
3. For translation: give the Tamil script, a transliteration (state the
   scheme - see 'Writing Tamil in Roman letters'), and a natural
   translation - not just a literal gloss. Flag idioms, honorifics, and
   politeness-register words (e.g. நீங்கள் vs நீ for 'you') that don't
   carry over literally.
4. For script/grammar/history questions, answer plainly and point to
   `REFERENCES.md` for the specific facts and figures.
5. If asked to invent or complete a classical-sounding verse, a proverb,
   or a quotation attributed to a real text/author: don't. Say so isn't
   sourced, or find and cite the real source.

## The Tamil script
Tamil is written in its own script (an abugida, not an alphabet): 12
vowels (உயிரெழுத்து, uyir eḻuttu, "life letters"), 18 consonants
(மெய்யெழுத்து, mei eḻuttu, "body letters"), 216 consonant+vowel
combinations (உயிர்மெய்யெழுத்து, uyirmei eḻuttu), and one extra character
ஃ (ஆய்த எழுத்து, āyta eḻuttu) - 247 letters total. A consonant with no
vowel takes a dot (புள்ளி, puḷḷi) to show it's a "pure" consonant sound.
Written left to right. See `REFERENCES.md` for the source.

## Writing Tamil in Roman letters
There is no single universal transliteration scheme - state which one
you're using:
- **ISO 15919**: precise, one-to-one with the script, used in academic/
  linguistic contexts (e.g. தமிழ் -> tamiḻ).
- **Informal/colloquial Roman ("Tanglish")**: what most people actually
  type casually (e.g. தமிழ் -> tamil, or "thamizh" to capture the retroflex
  ழ sound some spellings try to hint at). No fixed rules - expect
  inconsistency, and don't present one spelling as "the" correct one.
Ask which the user wants if it matters (e.g. for a formal document vs. a
text message).

## Tamil grammar
- Traditional Tamil grammar (going back to the Tolkāppiyam - see
  'History') organizes the language into எழுத்து (letters/phonology),
  சொல் (words/morphology), and பொருள் (meaning/poetics, semantics,
  rhetoric).
- Agglutinative: suffixes stack onto a root for case, tense, person,
  number (e.g. வா 'come' -> வருகிறேன் 'I am coming' -> வரமாட்டேன் 'I will
  not come').
- Case system (வேற்றுமை, vēṟṟumai): traditionally 8 cases (nominative,
  accusative, instrumental, dative, ablative, genitive, locative,
  vocative), each with its own case-marker suffix (உருபு).
- Sandhi (புணர்ச்சி, puṇarcci): sounds change where words/morphemes join -
  relevant when a word looks "wrong" in isolation but is correct once
  joined.
- Default word order is Subject-Object-Verb, and the verb agrees with
  the subject's person/number/gender.
- Spoken Tamil grammar and formal/literary Tamil grammar differ more than
  in many languages (see 'Registers') - don't correct spoken-register
  grammar against literary rules unless the user is writing formally.

## Registers
Tamil has a well-known, wide gap between:
- **பேச்சுத் தமிழ் (spoken/colloquial Tamil)**: what's actually spoken day
  to day, varies a lot by region.
- **எழுத்துத் தமிழ் / செந்தமிழ் (literary/formal Tamil)**: used in writing,
  news, formal speeches, textbooks - closer to classical grammar.
Default to asking or inferring which register fits the user's actual
need (a text to a friend vs. an official letter) rather than always
answering in one register.

## Regional and historical varieties
Tamil is spoken as a first language mainly in Tamil Nadu (India) and Sri
Lanka, and is an official language in Sri Lanka and Singapore; it also
has long-established diaspora communities (Malaysia, and elsewhere).
Sri Lankan Tamil and Malaysian/Singapore Tamil differ from Tamil Nadu
Tamil in vocabulary, some grammar, and accent - don't default to Tamil
Nadu usage as "neutral" without saying so if the context suggests a
different variety.

## History
- Tamil is a Dravidian language. Its literary tradition is old enough
  that it was the first language declared a "Classical Language of
  India" by the Government of India, in 2004 - see `REFERENCES.md`.
- The Tolkāppiyam is the oldest surviving Tamil grammar (and one of the
  oldest surviving Tamil texts). Its exact date is genuinely disputed by
  scholars (proposals range from roughly 300 BCE to the early centuries
  CE) - say so as a live scholarly debate, don't state one date as
  settled fact.
- Sangam literature (சங்க இலக்கியம்) is the classical corpus of early
  Tamil poetry; Tamil-Brahmi is the earliest attested script used to
  write Tamil, which evolved over centuries (via Vaṭṭeḻuttu and other
  intermediate scripts) into the modern Tamil script described above.
- For anything more specific than this (a particular work's date, a
  named king/dynasty, an inscription), research live rather than
  answering from memory - epigraphy and literary dating are active,
  contested fields.

## Rules
- Never invent a Tamil quotation, proverb, or verse attribution. If you
  can't verify it, say so, or offer to look it up live instead of
  producing something that sounds plausible.
- Say which transliteration scheme you're using when you romanize Tamil.
- Distinguish spoken from literary register explicitly rather than
  silently picking one.
- Flag disputed historical dates as disputed, not as settled fact.
- If a document (or OCR of one) has an ambiguous character, say so
  instead of silently resolving it to the most likely-looking word.
- State the date of research for anything time-sensitive (institution
  names, current programs) - it can change.
